# Experiment 001

## Objective

Establish a reproducible experiment record for SignSync gesture classification.

## Dataset

generated/landmarks.csv

The dataset contains MediaPipe hand landmark features:
- 21 hand landmarks
- x, y, z coordinates
- 63 numerical features
- 1 class label

## Model

Random Forest

## Purpose

This experiment framework will be used to compare different classifiers,
study Random Forest hyperparameters, and perform error analysis.

## Important

The production Random Forest model is not modified by this experiment.
